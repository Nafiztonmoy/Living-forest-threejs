# A Forest - Topic 17

CSE4204 Computer Graphics Lab project built with Three.js, WebGL, and custom GLSL shaders.

## Requirements

- A modern browser with WebGL 2 support
- Node.js 18+ (recommended: current LTS)
- Internet connection while running, because Three.js is loaded from a pinned CDN mirror
- **Python is not required**

## Project structure

```text
computerGraphics3js/
|-- index.html
```

## Main features

- Textured procedural 3D forest and cliffs
- Perspective camera
- Keyboard and mouse camera interaction
- Mouse-controlled light presets
- Custom GLSL foliage and water shaders
- Procedural gradient sky, clouds, and sun glow
- Spring Sakura blossoms and falling petals
- Strong pink ground blanket during early Spring
- Summer green foliage
- Autumn orange/red/gold leaves and heavy leaf fall
- Winter snow, bare branches, and white ground
- Animated river and wooden bridge

## Run on Windows

The easiest method is to double-click:

```text
START_WINDOWS.bat
```

Or open a terminal in the project folder and run:

```bash
npm start
```

Then open:

```text
http://127.0.0.1:8000
```

Keep the terminal open while viewing the project.

### If `node` or `npm` is not recognized

Install the current **Node.js LTS** release, then close and reopen the terminal. No Python installation is needed.

## Test

```bash
npm test
```

## Build

```bash
npm run build
```

This creates the deployable multi-file copy in `dist/` using Node.js only.

## Controls

- `W A S D` - move
- Arrow keys - look/orbit
- `Q / E` - lower/raise camera
- Mouse drag - orbit
- Mouse wheel - zoom
- Click scene or `L` - cycle lighting
- `1 / 2 / 3 / 4` - Spring / Summer / Autumn / Winter
- `Space` - pause/resume season cycle
- `R` - reset camera
- `H` - hide/show UI
